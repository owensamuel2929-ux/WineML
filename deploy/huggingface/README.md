#  Wine Quality ML

Interactive demo for a machine-learning system that predicts red wine quality
from physicochemical measurements, following Cortez et al. (2009).

This Space is the **deployment artifact** of the
[WineML repository](https://github.com/owensamuel2929-ux/WineML). The source of
truth lives there; this repository is assembled from it by
`scripts/deploy_hf_space.sh` so the main project can keep its two-service
Docker Compose setup.

## The problem it solves

The dataset's stated goal is to *"determine which physiochemical properties make
a wine 'good'"*. This project answers that with two models trained on the same
features:

| Task | Target | Primary metric | Result |
|---|---|---|---|
| Classification | `is_good` = quality ≥ 7 | PR-AUC | **0.848** |
| Regression | `quality` (3–8) | RMSE | **0.604** |

**Why PR-AUC and not accuracy?** Only 13.6% of wines clear the cutoff — a 6.4:1
imbalance. A model that predicts "never good" scores 86.4% accuracy while
finding zero good wines. ROC-AUC and accuracy both hide that failure; average
precision exposes it.

## Verified results

```
ROC-AUC 0.942  ·  PR-AUC 0.848  ·  F1 0.727  ·  Recall 0.744
RMSE 0.604  ·  MAE 0.438  ·  R² 0.504
126 tests passing  ·  93% coverage
```

`RandomForestClassifier` and `RandomForestRegressor` were selected by 5-fold
cross-validation over three candidates per task.

## What makes a wine good?

The classifier's feature importances answer the inspiration question directly:
`alcohol` is the strongest signal, followed by `volatile acidity` and
`sulphates`. These are **correlations, not causes** — the dataset card
explicitly warns against causal readings.

## Design note

Preprocessing lives **inside** the serialized scikit-learn pipeline. The scaler
is fitted during training and saved with the estimator, so inference replays the
exact transformation the model was trained on. Train/serve skew is structurally
impossible rather than merely discouraged.

## Limitations

- **Red wine only** — the white wine variant is not included.
- **Regression to the mean** — the regressor rarely predicts extreme scores (3
  or 8) because few such wines exist. Predictions cluster in the 5–6 range.
- **R² of 0.504** — most quality variation is driven by factors this dataset
  does not capture, such as grape variety and winemaking technique.
- **No causal claims** — importances are statistical associations.
